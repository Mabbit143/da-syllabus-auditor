UO Color Contrast
This page provides quick reference tables for determining whether different combinations of UO brand colors meet color contrast requirements for accessibility.
UO brand colors were updated in August, 2026 - to view contrast tables for the old brand colors, visit the Old Brand Color Contrast page.
"Color contrast" refers to the contrast difference between the color used for text, UI controls, or essential graphical elements against the color background they are on. For general information about color contrast accessibility, visit the Color Guidelines page.
The tables on this page are also available as an Excel spreadsheet, which can be downloaded here .
Technical Standards
WCAG SC 1.4.3: Contrast (Minimum)
WCAG SC 1.4.11: Non-Text Contrast
Allowed Use
Yes : Allowed for all text, UI controls, and essential graphical elements (e.g., icons, focus indicators).
Large Only : Only allowed for large text (at least 18pt or at least 14pt bold), UI controls, and essential graphical elements (e.g., icons, focus indicators).
No : Not allowed for any text, UI controls, or graphical elements, unless inactive, purely decorative, or part of a logo.
In addition to text, "Yes" cells are presented using bold text and a green background, "Large Only" cells use italic text and a yellow background, and "No" cells use a red background and the text isn't bold or italic.

Contrast Ratios (x:1)
All contrast ratios in this table are against 1. For example, a value of "4.8" in the table is a contrast ratio 4.8:1.
The minimum contrast ratio for text is 4.5:1 and the minimum contrast ratio for large text (at least 18pt or at least 14pt bold), UI controls, and essential graphical elements (e.g., icons, focus indicators) is 3:1.
In addition to text, cells with a value of at least 4.5 ("Yes" cells in the Allowed Use table) are presented using bold text and a green background, cells with a value of 3 to 4.5 ("Large Only" cells in the Allowed Use table) use italic text and a yellow background, and cells with a value below 3 ("No" cells in the Allowed Use table) use a red background and the text isn't bold or italic. These styles are identical to the "Allowed Use" table.
